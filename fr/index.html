Comment télécharger une vidéo Pinterest

1

Ouvrez le Pin sur Pinterest et copiez son lien depuis le menu de partage ou la barre d'adresse.

2

Collez le lien copié dans le champ de PinViddl, puis cliquez sur Télécharger.

3

PinViddl trouve la vidéo. Cliquez sur le lien de téléchargement pour l'enregistrer sur votre appareil.

Ce qui se passe quand vous collez le lien d'un Pin

PinViddl est un téléchargeur de vidéos Pinterest qui part du lien d'un Pin. Vous lui donnez l'adresse d'un Pin public, il cherche le média qui y est associé et propose le fichier au téléchargement. Il ne vous demande jamais vos identifiants Pinterest et ne touche pas à vos tableaux. C'est ce qui le distingue du bouton Enregistrer de Pinterest, qui place un Pin dans l'un de vos tableaux au lieu de déposer un fichier sur votre appareil.

Quand vous cliquez sur Télécharger, votre navigateur vérifie d'abord que le texte ressemble à une adresse de Pin Pinterest. Si ce n'est pas le cas, un court message s'affiche aussitôt et rien n'est envoyé. Sinon, le lien part vers le serveur de PinViddl, qui fonctionne sur Cloudflare Workers : il recherche le Pin et renvoie le média trouvé. Vous voyez alors un lecteur d'aperçu et une ligne par fichier, avec un bouton de téléchargement et un bouton pour copier l'URL. Ce dernier copie l'adresse directe du fichier, pas celle du Pin.

Seuls les Pins publics peuvent être récupérés. Si un Pin est privé ou a été supprimé, l'outil n'a rien à retrouver.

Quels liens Pinterest sont pris en charge ?

Pinterest utilise plusieurs types d'adresses, et seules certaines mènent à une vidéo précise. PinViddl en accepte deux :

  • Un lien de Pin, par exemple https://www.pinterest.com/pin/1234567890/. Le même format /pin/ est accepté sur plusieurs domaines nationaux de Pinterest.
  • Un lien court pin.it, par exemple https://pin.it/abc123, l'adresse raccourcie que Pinterest crée quand vous partagez un Pin.

Les liens vers un tableau, un profil, une page de résultats de recherche ou votre fil d'accueil affichent plusieurs Pins à la fois : il n'y a donc pas de vidéo unique à récupérer, et ils sont refusés.

Collez l'adresse complète, https:// compris. Les liens copiés depuis l'application Pinterest ou la barre d'adresse d'un navigateur l'incluent déjà. Un lien saisi à la main sans ce préfixe sera refusé. Si vous hésitez sur ce que vous avez copié, ouvrez-le dans un nouvel onglet : si vous arrivez sur un seul Pin, avec sa propre page, c'est le bon type de lien.

Enregistrer la vidéo sur votre téléphone ou votre ordinateur

PinViddl fonctionne dans le navigateur : l'endroit où la vidéo est enregistrée dépend donc de votre navigateur et des réglages de votre appareil, pas de PinViddl.

  • Android : dans l'application Pinterest, ouvrez le Pin, touchez Partager, puis choisissez Copier le lien (les libellés varient un peu selon les versions). Collez-le dans PinViddl depuis votre navigateur. Le fichier arrive généralement dans le dossier Téléchargements, accessible depuis un gestionnaire de fichiers.
  • iPhone : les étapes sont les mêmes. Safari enregistre normalement les téléchargements dans l'app Fichiers, sous Téléchargements. Pour retrouver la vidéo dans Photos, ouvrez-la depuis Fichiers, touchez Partager, puis choisissez Enregistrer la vidéo.
  • Windows et Mac : copiez le lien depuis la barre d'adresse ou le menu de partage du Pin. Le fichier va dans le dossier de téléchargements habituel de votre navigateur, ou une fenêtre d'enregistrement s'affiche si votre navigateur est réglé pour demander où enregistrer.

Qualité et type de fichier de la vidéo

PinViddl n'a aucun réglage de résolution. Il liste le ou les fichiers vidéo trouvés pour le Pin, et chaque ligne indique une mention de qualité quand elle est disponible. Si un Pin existe en plusieurs versions, vous verrez plusieurs lignes ; s'il n'en a qu'une, vous n'en verrez qu'une.

Le résultat dépend de ce que l'auteur a mis en ligne et de ce que Pinterest diffuse pour ce Pin : un petit clip en basse résolution ne deviendra pas plus net en étant téléchargé. Après l'enregistrement, vérifiez la résolution réelle dans les informations du fichier ou dans le panneau d'informations d'un lecteur vidéo. Les Pins vidéo arrivent normalement sous forme de fichiers MP4, mais le format est celui que Pinterest fournit pour ce Pin.

Certaines vidéos comportent un logo ou une légende incrustés dans l'image par leur créateur. Cela fait partie de la vidéo elle-même, et PinViddl ne peut pas l'enlever.

Si un Pin ne se télécharge pas

La plupart des échecs tiennent au lien ou au Pin, et le message affiché à l'écran indique en général lequel :

  • Un message demande une URL Pinterest valide. Le texte n'est pas une adresse de Pin ou de lien pin.it. Il peut s'agir d'un lien de tableau, de profil ou de recherche, d'une adresse copiée à moitié, ou d'une adresse sans https://.
  • Un message évoque le caractère public du Pin. Le Pin est peut-être privé ou supprimé, ou la recherche a échoué ponctuellement. Ouvrez le lien dans une fenêtre de navigation privée ou sans être connecté. Si Pinterest ne vous montre pas le Pin dans ce cas, PinViddl ne pourra très probablement pas le lire non plus.
  • Un message indique qu'aucun média téléchargeable n'a été trouvé. La recherche n'a renvoyé aucun fichier pour ce Pin. Vérifiez sur Pinterest qu'il contient bien une vidéo, et non une photo ou une animation en boucle.
  • L'aperçu est vide, mais le bouton de téléchargement est là. L'aperçu et le téléchargement sont deux requêtes distinctes : l'une peut échouer pendant que l'autre fonctionne. Essayez quand même le bouton de téléchargement.
  • Un Pin qui fonctionnait ne fonctionne plus. Pinterest peut modifier la façon dont il diffuse ses médias. Si un Pin public échoue de façon répétée, envoyez le lien via la page Contact pour qu'il soit examiné.

Vidéo, image ou GIF ?

Dans le fil, les Pins se ressemblent, mais ils ne contiennent pas la même chose. Un Pin vidéo a des commandes de lecture. Une courte boucle qui se lance toute seule, sans commandes, est souvent une animation de type GIF. Une image fixe est une image. Ce que vous recevez dépend de ce que le Pin contient réellement ; PinViddl propose donc une page distincte pour chaque cas :

Téléchargeur d'images Pinterest Pour les photos et les graphismes fixes.
Téléchargeur de GIF Pinterest Pour les Pins animés en boucle.

Pour les Pins image ordinaires, Pinterest propose aussi sa propre option Télécharger l'image dans le menu ⋯ du Pin. Sa page d'aide (en anglais) précise que tous les Pins ne peuvent pas être téléchargés de cette façon.

Utiliser les vidéos téléchargées de façon responsable

Le fait qu'un Pin soit public ne rend pas sa vidéo libre de réutilisation. Les droits restent à la personne qui l'a créée ou publiée. Enregistrer un clip pour le regarder hors connexion n'est pas la même chose que le republier, l'intégrer à votre propre création ou l'utiliser dans un cadre commercial : dans ces cas-là, demandez d'abord l'accord du créateur. Ce qui est autorisé dépend aussi de votre pays et des conditions d'utilisation de Pinterest, que PinViddl ne contrôle pas.
