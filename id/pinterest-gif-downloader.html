Apa fungsi Pinterest GIF Downloader ini?

Sebagian Pin bergerak. Pin itu berputar sendiri, dan kalau Anda mencoba menyimpannya seperti menyimpan foto, hasilnya sering cuma satu gambar diam, atau malah tidak ada yang bisa dipakai. Halaman ini dibuat untuk situasi seperti itu. Anda memberi PinViddl tautan satu Pin publik, alat ini memeriksa media animasi apa yang sebenarnya dimiliki Pin tersebut, lalu menawarkan unduhannya.

Yang bisa dilakukan alat ini:

  • Membaca satu Pin publik dari tautannya.
  • Menawarkan file animasi yang dimiliki Pinterest untuk Pin itu.
  • Berjalan di browser biasa di HP, tablet, atau komputer.

Yang tidak bisa dilakukan:

  • Mengubah video menjadi GIF, atau GIF menjadi video.
  • Mengunduh board, profil, atau halaman pencarian.
  • Membuka Pin privat.
  • Meningkatkan kualitas file aslinya.

Satu hal yang perlu diketahui sebelum mulai: file yang Anda dapat tidak selalu berupa .gif. Bagian tentang GIF dan MP4 di bawah menjelaskan alasannya dan apa yang bisa dilakukan.

Cara mengunduh GIF dari Pinterest

  1. Buka Pin animasi di aplikasi Pinterest atau di pinterest.com.
  2. Salin tautannya (penjelasan di bawah).
  3. Tempel tautan di kotak paling atas halaman ini, atau pakai tombol Tempel.
  4. Pilih Unduh GIF. Bilah progres akan tampil selagi PinViddl mencari media Pin tersebut.
  5. Simpan file saat opsi unduh muncul. Untuk mengambil file lain, pilih Unduh file lainnya.

Menyalin tautan di aplikasi Pinterest. Buka Pin sampai memenuhi layar. Tergantung versi aplikasi, opsinya ada di bawah Bagikan atau di balik menu tiga titik. Apa pun lokasinya, yang Anda cari adalah Salin tautan.

Menyalin tautan di browser. Klik Pin sampai terbuka di halamannya sendiri, lalu salin alamat dari address bar. Kalau Anda masih berada di halaman board atau pencarian dengan Pin tampil sebagai pop-up, pastikan alamatnya sudah mengandung /pin/ sebelum disalin.

Setelah mengunduh, cek apa yang Anda dapat. Lihat nama filenya. Seharusnya berakhiran .gif atau .mp4. Kalau perangkat Anda menyembunyikan ekstensi, buka detail filenya (klik kanan lalu Properties di Windows, Get Info di Mac, atau tekan dan tahan file di aplikasi File di iPhone). Bagian berikutnya menjelaskan arti tiap hasil.

Hasilnya GIF atau MP4?

GIF adalah format gambar. File .gif berisi urutan frame, masing-masing dibatasi 256 warna, tanpa suara. Format video seperti MP4 biasanya menyimpan data lebih sedikit untuk klip yang sama, itulah sebabnya banyak situs yang tampak menampilkan GIF sebenarnya memutar file MP4 kecil secara berulang. Di halaman Pin, keduanya terlihat sama persis, jadi Anda tidak bisa membedakannya hanya dengan menonton.

PinViddl tidak menebak. Alat ini memeriksa media apa yang dimiliki Pin lalu menawarkan itu:

  • Kalau media Pin berupa GIF, Anda mengunduh GIF.
  • Kalau berupa video, Anda mengunduh file video. File itu akan berulang di sebagian besar pemutar, tetapi bukan berupa .gif.
  • Kalau tidak ada keduanya dalam bentuk yang bisa ditawarkan PinViddl, tidak ada unduhan. Lihat panduan kegagalan di bawah.
Yang Anda dapat Artinya Yang bisa dilakukan

File .mp4 Media Pin-nya berupa video Banyak aplikasi akan memutar klip pendek seperti ini secara berulang. Kalau Anda butuh file .gif sungguhan, konversikan.
Tidak ada PinViddl tidak menemukan media yang bisa dipakai Lihat “Kalau unduhan gagal”

PinViddl tidak mengonversi file, dan tidak merekomendasikan konverter tertentu. Kalau Anda mengonversi MP4 menjadi GIF, ingat tiga hal. Hasilnya adalah file baru buatan konverter itu, bukan file aslinya. Hasilnya dibatasi 256 warna per frame. Ukurannya biasanya lebih besar daripada videonya. Kalau konverter Anda memungkinkan, pertahankan dimensi aslinya. Menurunkan frame rate atau ukuran memang mengecilkan file, tetapi mengorbankan kehalusan gerakan.

Anda mendapat file sebagaimana disimpan Pinterest untuk Pin tersebut. PinViddl tidak melakukan upscale, mempertajam, atau mengompres ulang, jadi hasilnya tidak mungkin lebih bagus daripada sumbernya. Sumbernya juga bisa berbeda dari yang pertama kali diunggah kreator, karena platform sering memproses unggahan.

PinViddl tidak mencantumkan resolusi karena tidak ada satu angka yang bisa diberikan. Dimensi dan frame rate berbeda dari satu Pin ke Pin lain. Label seperti 1080p atau 4K adalah istilah video. GIF cukup punya ukuran piksel, dan tidak ada downloader yang bisa menambah piksel yang tidak dimiliki sumbernya.

Dua ciri datang dari format GIF itu sendiri, bukan dari downloader mana pun. Warna dibatasi 256 per frame, sehingga gradasi yang halus bisa tampak berundak. Ukuran file juga bisa mengejutkan besarnya, bahkan untuk animasi beberapa detik.

Pinterest GIF Downloader di HP atau komputer

PinViddl berjalan di browser Anda, jadi langkahnya sama di semua perangkat. Yang berbeda hanya tempat file tersimpan.

  • Android: salin tautan Pin di aplikasi Pinterest, tempel ke PinViddl di browser HP, lalu unduh. File biasanya masuk ke folder Downloads. Pindahkan ke galeri kalau Anda ingin file itu ada di sana.
  • iPhone dan iPad: langkahnya sama di Safari. File tersimpan di aplikasi File, di folder Downloads, bukan di Foto. Untuk menambahkannya ke Foto, buka di File, ketuk Bagikan, lalu pilih Simpan Gambar atau Simpan Video. Yang muncul tergantung jenis filenya.
  • Windows dan Mac: file masuk ke folder Downloads atau muncul jendela penyimpanan, tergantung pengaturan browser Anda.

Ada dua hal kecil yang sering membuat orang bingung. Sebagian browser membuka file media di tab baru, bukan menyimpannya. Kalau itu terjadi, tekan dan tahan file (atau klik kanan) lalu pilih opsi simpan atau unduh tautan di browser. Dan beberapa aplikasi galeri menampilkan GIF yang tersimpan sebagai satu frame diam. Kalau punya Anda tidak bergerak, buka file itu di browser atau aplikasi pesan untuk memastikan animasinya masih utuh.

Kalau unduhan gagal

Pesan error di alat ini berasal dari alatnya sendiri dan mungkin tampil dalam bahasa Inggris. Berikut penyebab yang umum.

Masalahnya di tautan

  • Tautan mengarah ke board, profil, atau halaman pencarian. Buka satu Pin lalu salin tautannya sendiri.
  • Tautan terpotong saat disalin. Salin ulang secara lengkap.
  • Tautan bagikan pin.it sudah kedaluwarsa atau salah salin. Salin ulang dari menu Bagikan.

Masalahnya di Pin

  • Pin sudah dihapus. Buka di Pinterest. Kalau sudah hilang, tidak ada yang bisa diunduh.
  • Pin privat atau dibatasi. Hanya Pin publik yang bisa dibaca.
  • Pin berupa gambar diam. Pakai Pinterest Image Downloader.
  • Pin berupa video biasa. Pakai Pinterest Video Downloader.
  • Pin tidak punya media yang bisa ditawarkan PinViddl. Coba lagi nanti. Kalau terus gagal, Pin itu tidak bisa diunduh di sini.

Masalah di luar Pin

  • Pinterest sedang lambat atau sementara menolak permintaan. Tunggu beberapa menit lalu coba lagi.
  • Pinterest mengubah cara halamannya dibuat. PinViddl membaca halaman Pin publik, jadi perubahan di sisi Pinterest bisa mengganggu pencarian sampai disesuaikan.
  • Masalah koneksi atau browser. Muat ulang halaman, cek koneksi, atau coba browser lain. Browser yang sudah usang atau pemblokir yang terlalu agresif bisa mengganggu alat web apa pun.

Masih buntu? Kirim tautan Pin, perangkat dan browser Anda, serta kira-kira kapan kejadiannya lewat halaman Kontak. Tautan yang seharusnya bisa tetapi gagal adalah informasi yang berguna bagi kami.

Apa yang dibutuhkan PinViddl dari Anda

Hanya tautan Pin. Tidak ada login Pinterest, tidak ada akun PinViddl, dan tidak ada langkah pendaftaran di halaman ini.

Beginilah nasib tautan Anda. Tautan dikirim ke backend PinViddl yang berjalan di Cloudflare Workers. Backend mengambil halaman Pin publik dari Pinterest dan mengekstrak alamat medianya. Menurut Kebijakan Privasi:

  • Log server standar, termasuk alamat IP dan stempel waktu, disimpan hingga 30 hari untuk keamanan dan pencegahan penyalahgunaan.
  • Data analitik bersifat agregat dan disimpan hingga 26 bulan.
  • Situs ini tidak memakai jaringan iklan atau piksel pelacak media sosial.
