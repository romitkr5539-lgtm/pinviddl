Unduh Gambar Animasi dari Pinterest

Beberapa Pin tidak berhenti bergerak. Mereka berulang, mengulang, dan berperilaku seperti mini-video — kursor bergerak, urutan menari, atau meme yang bergantian antar adegan. Jika Anda telah mencoba menyimpan salah satunya dengan cara yang sama seperti Anda menyimpan foto biasa, Anda sudah tahu itu tidak berhasil. Mengklik kanan salah satu Pin tersebut hanya memberi Anda bingkai diam bukan file bergerak.

PinViddl telah dibuat untuk mengisi celah ini. Masukkan tautan ke Pin publik mana pun, dan PinViddl akan menyelidiki media bergerak atau yang dapat diunduh apa yang terlampir padanya dan menyajikan tautan untuk mengunduh apa yang ditemukannya. Ini mungkin tidak selalu berupa file .gif, karena Pinterest tidak menyimpan setiap Pin animasi dalam format yang sama.

Bagaimana Pin Animasi Pinterest Bekerja

Proses mendapatkan file ini mudah: temukan Pin, ambil tautannya, dan tunggu PinViddl mengambil media darinya. Namun, ada baiknya mengetahui apa yang akan Anda unduh sebelumnya. Pin animasi tidak selalu berupa file GIF hanya karena mereka bergerak — media yang mendasarinya bisa berupa GIF atau klip video, yang berarti proses unduhan dan cara Anda melihat file akan berbeda dalam kedua kasus tersebut.

Cara Mengetahui Apakah Pin Pinterest adalah GIF

Sebelum mengunduh, pertimbangkan bagaimana Pin berperilaku di halaman:

  • Berulang tanpa kontrol. GIF biasanya mulai diputar segera setelah muncul di tampilan tanpa tombol putar/jeda, bilah kemajuan, atau interaksi penampil yang diperlukan.
  • Gerakan pendek dan berulang. GIF biasanya menampilkan klip pendek yang diputar berulang kali — biasanya hanya beberapa detik.
  • Tidak ada kontrol video yang terlihat. Sebaliknya, video Pinterest biasanya akan menampilkan scrubber, tombol bisu, atau kontrol pemutaran lainnya.
  • Satu gambar diam bukan GIF. Jika tidak ada yang bergerak, Anda mungkin memiliki foto atau grafik statis bukan GIF.

Ini adalah petunjuk visual yang berguna, tetapi tidak mengungkapkan format file yang sebenarnya. Pinterest dapat menyajikan materi animasi dalam berbagai format, dan Anda tidak dapat mengetahui format yang tepat sampai Anda menjalankan Pin melalui PinViddl.

GIF Pinterest ke GIF

Jika media yang mendasari Pin adalah file GIF, Anda akan menerima file GIF tersebut secara langsung — tidak perlu konversi. Namun, PinViddl tidak dapat mengonversi Pin video menjadi file GIF. Jika media di balik Pin adalah video, itulah yang akan Anda unduh. Anggap hasil "GIF ke GIF" sebagai menerima file asli apa adanya, bukan yang dikonversi.

Kualitas dan Animasi GIF

Beberapa hal memengaruhi bagaimana GIF yang diunduh terlihat dan seberapa besar filenya:

  • Dimensi. GIF biasanya dibuat dengan dimensi lebih rendah dari gambar atau video asli, yang membantu menjaga ukuran file tetap terkendali.
  • Kecepatan bingkai. Menjaga kecepatan bingkai tetap rendah menghasilkan GIF yang lebih kecil, tetapi gerakannya mungkin terlihat tersendat-sendat.
  • Keterbatasan warna. Format GIF hanya menyimpan hingga 256 warna per bingkai, yang dapat mengakibatkan hilangnya gradien dan realisme dibandingkan dengan video atau foto diam.
  • Ukuran file. Karena GIF menyimpan beberapa bingkai bukan satu, ukuran filenya lebih besar daripada gambar diam pada dimensi yang sama.
  • Perbedaan antara pratinjau dan asli. Apa yang Anda lihat di pratinjau Pinterest mungkin berbeda dari apa yang Anda dapatkan saat mengunduh, karena Pinterest mungkin telah mengompresi media untuk penggunaan web.

Apakah Pinterest Selalu Menyimpan GIF sebagai File GIF?

Tidak selalu. Apa yang Anda lihat berulang di halaman Pin dan apa yang sebenarnya disimpan dan disajikan Pinterest mungkin bukan format yang sama. Konten animasi bisa saja diunggah oleh pengguna dalam format selain .gif standar. Ini bisa terlihat seperti GIF secara visual tetapi belum tentu jenis file yang sama.

Inilah alasan mengapa PinViddl memeriksa setiap Pin individual alih-alih berasumsi semua Pin animasi adalah GIF. Jika Pin memiliki file GIF, itu akan ditawarkan seperti itu. Jika memiliki format lain, format itu akan ditawarkan sebagai gantinya.
