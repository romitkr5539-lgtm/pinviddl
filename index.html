What appears after you submit a Pin

PinViddl checks the public Pin and builds a row for each media result it can use. A row is labeled VIDEO, IMAGE, or GIF and has its own Download and Copy URL buttons. Copy URL copies that file’s direct media address, not the Pinterest Pin link.

The preview is loaded separately from the download links. PinViddl previews the primary result it finds; if the preview fails but a result row is visible, try its Download button.

Use the link to one public Pin

Paste a full Pinterest Pin address such as pinterest.com/pin/123456789, or a pin.it link that opens one Pin. Copy the link from Pinterest’s Share menu or from the browser after the Pin opens.

Board, profile, search, and home-feed links do not identify one Pin. Direct media URLs are not accepted here. Private, deleted, or sign-in-only Pins cannot be read.

Read the result label before you save

Use the type shown in the row to confirm you have the file you wanted. Animated Pins can arrive as a GIF or a video file such as MP4; this tool does not convert between formats.

When PinViddl cannot identify a quality value, it may display “Super HD Source” as a fallback label. That text is not a pixel measurement. Check the downloaded file’s details if you need its actual dimensions.

Where your browser puts the file

  • Android: check your browser’s Downloads list or your file manager’s Downloads folder.
  • iPhone or iPad: open Safari Downloads or Files → Downloads. Use Share in Files to save a compatible photo or video to Photos.
  • Windows or Mac: check the browser’s download list or Downloads folder. If the file opens in a tab, use the browser’s save option.

If a Pin does not return a file

  • Open the URL and confirm it leads to one individual Pin, not a board or search page.
  • Check that the Pin is public and still available. PinViddl does not sign in to Pinterest to access restricted content.
  • Choose the tab that matches the Pin. A still photo will not produce a video result.
  • If you see “No downloadable media found for this Pin,” try another public Pin or send the link and message through the Contact page.
