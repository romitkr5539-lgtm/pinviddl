Scaricare Immagini Animate da Pinterest

Alcuni Pin non smettono di muoversi. Si ripetono, si ripetono ancora e si comportano come mini-video — un cursore in movimento, una sequenza di danza o un meme che alterna tra le scene. Se hai provato a salvarne uno come salveresti una foto normale, sai già che non funziona. Un clic destro su uno di quei Pin ti dà solo un fotogramma fermo invece del file in movimento.

PinViddl è stato creato per colmare questa lacuna. Inserisci il link a qualsiasi Pin pubblico, e PinViddl esaminerà quali media in movimento o scaricabili sono allegati e ti presenterà un link per scaricare ciò che ha trovato. Potrebbe non essere sempre un file .gif, perché Pinterest non memorizza ogni Pin animato nello stesso formato.

Come Funzionano i Pin Animati di Pinterest

Il processo per ottenere il file è semplice: individua il Pin, prendi il link e aspetta che PinViddl recuperi il media. Tuttavia, aiuta sapere in anticipo cosa stai per scaricare. I Pin animati non sono sempre file GIF solo perché si muovono — il media sottostante potrebbe essere una GIF o una clip video, il che significa che il processo di download e come visualizzi il file saranno diversi in entrambi i casi.

Come Capire se un Pin di Pinterest è una GIF

Prima di scaricare, considera come si comporta il Pin sulla pagina:

  • Loop senza controlli. Le GIF in genere iniziano a riprodursi non appena entrano in vista senza un pulsante play/pausa, barra di avanzamento o qualsiasi interazione dello spettatore richiesta.
  • Movimenti brevi e ripetitivi. Le GIF di solito mostrano una breve clip che si ripete più e più volte — in genere lunga solo un paio di secondi.
  • Nessun controllo video visibile. Al contrario, un video di Pinterest mostrerà tipicamente una barra di scorrimento, un pulsante di disattivazione audio o altri controlli di riproduzione.
  • Una singola immagine immobile non è una GIF. Se nulla si muove, probabilmente hai una foto o un grafico statico piuttosto che una GIF.

Questi sono utili indizi visivi, ma non rivelano il formato effettivo del file. Pinterest può presentare materiale animato in vari formati, e non puoi scoprire il formato esatto finché non esegui il Pin attraverso PinViddl.

GIF Pinterest in GIF

Se il media sottostante di un Pin è un file GIF, riceverai quel file GIF direttamente — nessuna conversione necessaria. Tuttavia, PinViddl non può convertire un Pin video in un file GIF. Se il media dietro un Pin è un video, è quello che scaricherai. Pensa al risultato "GIF in GIF" come ricevere il file originale così com'è, non uno convertito.

Qualità e Animazione della GIF

Alcune cose influenzano l'aspetto di una GIF scaricata e quanto è grande il file:

  • Dimensioni. Le GIF sono solitamente create con dimensioni inferiori rispetto all'immagine o al video originale, il che aiuta a mantenere le dimensioni dei file gestibili.
  • Frame rate. Mantenere basso il frame rate produce GIF più piccole, ma il movimento potrebbe apparire a scatti.
  • Limitazioni di colore. Il formato GIF memorizza solo fino a 256 colori per fotogramma, il che può comportare una certa perdita di sfumature e realismo rispetto al video o a una fotografia ferma.
  • Dimensione del file. Poiché una GIF memorizza più fotogrammi anziché uno, la sua dimensione del file è maggiore di un'immagine ferma alle stesse dimensioni.
  • Differenze tra anteprima e originale. Ciò che vedi nell'anteprima di Pinterest potrebbe differire da ciò che ottieni quando scarichi, poiché Pinterest potrebbe aver compresso il media per l'uso web.

PinViddl fornisce qualsiasi file sia effettivamente disponibile dal Pin — non lo ingrandisce, ricomprime o altera in altro modo.

Pinterest Memorizza Sempre le GIF come File GIF?

Non sempre. Ciò che vedi in loop su una pagina Pin e ciò che Pinterest memorizza e serve effettivamente potrebbero non essere lo stesso formato. Il contenuto animato potrebbe essere stato caricato dall'utente in un formato diverso dal .gif standard. Potrebbe sembrare visivamente una GIF ma non sarà necessariamente lo stesso tipo di file.

Questo è il motivo per cui PinViddl controlla ogni singolo Pin invece di presumere che tutti i Pin animati siano GIF. Se il Pin ha un file GIF, sarà offerto come tale. Se ha un altro formato, quel formato sarà offerto invece.
