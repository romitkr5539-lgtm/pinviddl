Was nach dem Einfügen eines Pin-Links passiert

PinViddl ist ein Pinterest-Video-Downloader, der mit dem Link eines Pins arbeitet. Sie geben die Adresse eines öffentlichen Pins ein, das Tool sucht die Medien, die zu diesem Pin gehören, und bietet die Datei zum Download an. Eine Pinterest-Anmeldung ist nicht nötig, und Ihre Pinnwände bleiben unberührt. Genau hier liegt der Unterschied zum Speichern-Button von Pinterest: Er legt einen Pin auf einer Ihrer Pinnwände ab, statt eine Datei auf Ihrem Gerät zu speichern.

Wenn Sie auf „Herunterladen“ klicken, prüft Ihr Browser zuerst, ob der Text wie eine Pinterest-Pin-Adresse aussieht. Ist das nicht der Fall, erscheint sofort eine kurze Meldung, und es wird nichts gesendet. Andernfalls geht der Link an den PinViddl-Server, der auf Cloudflare Workers läuft. Dieser ruft den Pin ab und gibt die gefundenen Medien zurück. Anschließend sehen Sie einen Vorschau-Player und für jede Datei eine Zeile mit einem Download-Button und einem Button zum Kopieren der URL. Kopiert wird dabei die direkte Adresse der jeweiligen Datei, nicht der Pin-Link.

Abrufbar sind nur öffentliche Pins. Ist ein Pin privat oder wurde er gelöscht, kann das Tool nichts abrufen.

Welche Pinterest-Links funktionieren

Pinterest kennt mehrere Arten von Adressen, und nur manche führen zu einem bestimmten Video. PinViddl akzeptiert zwei davon:

  • Pin-Link, zum Beispiel https://www.pinterest.com/pin/1234567890/. Das Format mit /pin/ wird auch auf mehreren Länder-Domains von Pinterest akzeptiert.
  • Kurzlink von pin.it, zum Beispiel https://pin.it/abc123. Das ist die verkürzte Adresse, die Pinterest beim Teilen eines Pins erzeugt.

Links zu einer Pinnwand, einem Profil, einer Suchergebnisseite oder Ihrem Home-Feed zeigen viele Pins auf einmal. Es gibt dort also kein einzelnes Video, das sich abrufen ließe, und solche Links werden abgelehnt.

Fügen Sie die vollständige Adresse ein, einschließlich des https:// am Anfang. Links aus der Pinterest-App oder aus der Adresszeile eines Browsers enthalten es bereits. Ein von Hand getippter Link ohne diesen Anfang wird abgelehnt. Wenn Sie unsicher sind, was Sie kopiert haben, öffnen Sie den Link in einem neuen Tab: Landen Sie auf einem einzelnen Pin mit eigener Seite, ist es der richtige Linktyp.

Die Datei auf Smartphone oder Computer speichern

PinViddl läuft im Browser. Wo das Video landet, hängt daher von Ihrem Browser und den Geräteeinstellungen ab, nicht von PinViddl.

  • Android: Öffnen Sie den Pin in der Pinterest-App, tippen Sie auf „Teilen“ und wählen Sie „Link kopieren“ (die Bezeichnungen unterscheiden sich je nach App-Version leicht). Fügen Sie den Link in PinViddl im Browser ein. Die Datei landet in der Regel im Ordner „Downloads“, den Sie über einen Dateimanager öffnen können.
  • iPhone: Die Schritte sind dieselben. Safari speichert Downloads normalerweise in der Dateien-App im Ordner „Downloads“. Um das Video in die Fotos-App zu bekommen, öffnen Sie es in „Dateien“, tippen auf „Teilen“ und wählen „Video sichern“.
  • Windows und Mac: Kopieren Sie den Link aus der Adresszeile oder über das Teilen-Menü des Pins. Die Datei wird im normalen Download-Ordner Ihres Browsers gespeichert. Ist Ihr Browser so eingestellt, dass er nachfragt, erscheint stattdessen ein Speicherdialog.

Videoqualität und Dateityp

PinViddl hat keine eigene Auflösungseinstellung. Das Tool listet die Videodatei oder -dateien auf, die es für den Pin gefunden hat, und zeigt in jeder Zeile eine Qualitätsangabe, sofern eine verfügbar ist. Gibt es den Pin in mehreren Versionen, sehen Sie mehrere Zeilen; gibt es nur eine Version, sehen Sie nur eine.

Was Sie erhalten, hängt davon ab, was der Ersteller hochgeladen hat und was Pinterest für diesen Pin ausliefert. Ein kleiner Clip mit niedriger Auflösung wird durch den Download also nicht schärfer. Prüfen Sie nach dem Speichern die tatsächliche Auflösung in den Dateidetails Ihres Geräts oder im Infobereich eines Videoplayers. Video-Pins kommen normalerweise als MP4-Dateien an, das Format richtet sich aber nach dem, was Pinterest für den jeweiligen Pin bereitstellt.

Manche Videos enthalten ein vom Ersteller eingebranntes Logo oder eine Beschriftung. Das gehört zum Video selbst, und PinViddl kann es nicht entfernen.

Wenn ein Pin sich nicht herunterladen lässt

Die meisten Fehler hängen mit dem Link oder dem Pin zusammen, und die Meldung auf dem Bildschirm verrät meist, woran es liegt:

  • Eine Meldung, die eine gültige Pinterest-URL verlangt. Der Text ist keine Pin- oder pin.it-Adresse. Möglicherweise handelt es sich um den Link zu einer Pinnwand, einem Profil oder einer Suche, um eine unvollständig kopierte Adresse oder um eine Adresse ohne https://.
  • Eine Meldung, dass der Pin öffentlich sein muss. Der Pin ist vielleicht privat oder gelöscht, oder die Abfrage ist kurzzeitig fehlgeschlagen. Öffnen Sie den Link in einem privaten Browserfenster oder ohne Anmeldung. Wenn Pinterest Ihnen den Pin dort nicht anzeigt, kann PinViddl ihn höchstwahrscheinlich ebenfalls nicht lesen.
  • Eine Meldung, dass keine herunterladbaren Medien gefunden wurden. Für diesen Pin wurde keine Datei zurückgegeben. Prüfen Sie auf Pinterest, ob der Pin wirklich ein Video enthält und nicht ein Foto oder eine Endlosschleife.
  • Die Vorschau bleibt leer, aber der Download-Button ist da. Vorschau und Download sind getrennte Anfragen, sodass eine ausfallen kann, während die andere funktioniert. Probieren Sie den Download-Button trotzdem aus.
  • Ein Pin, der früher funktioniert hat, schlägt jetzt fehl. Pinterest kann die Art ändern, wie Medien ausgeliefert werden. Wenn ein öffentlicher Pin dauerhaft nicht funktioniert, schicken Sie den Link über die Kontaktseite, damit er geprüft werden kann.

Video, Bild oder GIF?

Im Feed sehen Pins ähnlich aus, enthalten aber Unterschiedliches. Ein Video-Pin hat Wiedergabesteuerung. Eine kurze Schleife, die ohne Steuerung von selbst abläuft, ist oft eine GIF-ähnliche Animation. Ein Standbild ist ein Bild. Was Sie erhalten, hängt davon ab, was der Pin tatsächlich enthält. Deshalb gibt es bei PinViddl für jeden Typ eine eigene Seite:

Pinterest-Bild-Downloader Für Fotos und Grafiken.
Pinterest-GIF-Downloader Für animierte Pins in Endlosschleife.

Für normale Bild-Pins bietet Pinterest außerdem selbst die Option „Bild herunterladen“ im ⋯-Menü des Pins an. Auf der Hilfeseite von Pinterest (auf Englisch) steht, dass sich nicht jeder Pin auf diesem Weg herunterladen lässt.

Dass ein Pin öffentlich ist, heißt nicht, dass sein Video frei verwendet werden darf. Die Rechte liegen bei der Person, die es erstellt oder veröffentlicht hat.
