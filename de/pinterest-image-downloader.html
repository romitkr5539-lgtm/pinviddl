Der Pinterest-Bild-Downloader von PinViddl macht aus einem Pin-Link eine Vorschau und einen Download. Fügen Sie den Link eines öffentlichen Pins ein, prüfen Sie das Bild und speichern Sie es auf Ihrem Smartphone oder Computer.

So laden Sie ein Bild von Pinterest herunter

  1. Pin-Link kopieren. Öffnen Sie auf pinterest.com den Pin, sodass er eine eigene Seite hat, und kopieren Sie die Adresse aus der Adresszeile Ihres Browsers. In der Pinterest-App tippen Sie auf den Pin, dann auf „Teilen“ und auf „Link kopieren“.
  2. Link in das Feld oben einfügen. Mit der Schaltfläche „Einfügen“ übernehmen Sie den Link aus der Zwischenablage, oder Sie fügen ihn selbst ein. Der Link muss mit https:// beginnen.
  3. Auf „Bild herunterladen“ klicken. Während PinViddl den Pin abruft, läuft ein paar Sekunden lang ein Fortschrittsbalken.
  4. Vorschau ansehen. Das Bild erscheint mit mindestens einer Zeile darunter. Jede Zeile hat eine Schaltfläche „URL kopieren“, die die direkte Adresse der Bilddatei kopiert, und eine Schaltfläche „Herunterladen“.
  5. Auf „Herunterladen“ klicken. Wo die Datei landet, hängt von Ihrem Gerät ab (siehe unten). Mit „Weiteres Bild herunterladen“ beginnen Sie mit einem neuen Link von vorn.

Auch Pinterest selbst bietet eine Möglichkeit. Laut der Hilfeseite von Pinterest (auf Englisch) enthält das ⋯-Menü bei manchen Pins die Option „Bild herunterladen“. Wenn sie da ist, nutzen Sie diese. PinViddl ist für die Fälle gedacht, in denen sie fehlt oder in denen Sie nur einen Link haben, den Ihnen jemand geschickt hat.

Welche Pinterest-Links funktionieren

  • https://www.pinterest.com/pin/123456789/ – Funktioniert. Das ist der normale Pin-Link.
  • https://pin.it/AbCd123 – Funktioniert meistens. Das sind die Kurzlinks aus dem Teilen-Menü von Pinterest. Wenn einer nicht klappt, öffnen Sie ihn im Browser und kopieren stattdessen die vollständige Adresse.
  • https://in.pinterest.com/pin/… oder https://pinterest.co.uk/pin/… – Funktioniert. Länderspezifische Adressen, die in der Liste des Tools stehen, werden akzeptiert.
  • Link zu einem Board, Profil oder einer Suche – Wird abgelehnt. Diese Links führen zu vielen Bildern statt zu einem. Öffnen Sie den gewünschten Pin und kopieren Sie dessen Link.
  • Direkte Bildadresse (i.pinimg.com/…) – Wird abgelehnt. Verwenden Sie den Link zur Seite des Pins.
  • Link ohne https:// – Setzen Sie https:// an den Anfang.

Einige weniger verbreitete Pinterest-Domains werden nicht erkannt. Wird Ihre abgelehnt, ersetzen Sie die Domain durch www.pinterest.com und behalten /pin/ samt der Nummer dahinter bei. Das funktioniert meist.

Das Bild auf iPhone, Android oder Computer speichern

PinViddl übergibt die Datei an Ihren Browser. Was danach passiert, hängt daher vom jeweiligen Browser ab.

  • iPhone (Safari). Die Datei landet möglicherweise in der Dateien-App im Ordner „Downloads“ oder öffnet sich als normales Bild. Öffnet sie sich, halten Sie das Bild gedrückt und wählen „Zur Fotomediathek hinzufügen“.
  • Android (Chrome). Downloads werden normalerweise im Ordner „Downloads“ gespeichert, und manche Galerie-Apps zeigen sie getrennt an. Öffnet sich das Bild stattdessen in einem Tab, halten Sie es gedrückt und wählen „Bild herunterladen“.
  • Computer. Chrome, Edge, Firefox und Safari speichern Dateien normalerweise im Ordner „Downloads“. Öffnet sich das Bild in einem Tab, klicken Sie mit der rechten Maustaste darauf und wählen „Bild speichern unter“.

Was Sie bei der Bildqualität erwarten können

PinViddl sucht die Bilddatei, die zum Pin gehört, und gibt sie an Sie weiter. Das Tool vergrößert, schärft oder verbessert nichts. Das Ergebnis kann daher nicht besser sein als das, was Pinterest für diesen Pin vorhält.

Das ist wichtig, weil das Bild im Feed oft nur eine verkleinerte Kopie des Uploads ist und manche Uploads von Anfang an klein waren. Wirkt ein Download kleiner als erhofft, prüfen Sie, ob der Pin selbst eine niedrige Auflösung hat.

Was Sie tatsächlich bekommen haben, sehen Sie an den Abmessungen der Datei und nicht an einer Bezeichnung: unter Windows in den Eigenschaften, am Mac über „Informationen“ oder in der Infoansicht der Foto-App Ihres Smartphones. Brauchen Sie ein größeres Bild, suchen Sie am besten auf der Website oder im Portfolio des Urhebers.

Der Dateityp richtet sich danach, was Pinterest für den Pin ausliefert, meist JPG, manchmal PNG oder WebP. PinViddl ist kein Konverter, deshalb lässt sich das Format nicht ändern.

Wenn der Download nicht funktioniert

Bei Problemen zeigt das Tool kurze Meldungen an. Hier steht, was sie meistens bedeuten.

  • Meldung, dass Sie eine gültige Pinterest-URL eingeben sollen. Der Link wurde abgelehnt, bevor etwas gesendet wurde. Prüfen Sie, ob er mit https:// beginnt, /pin/ mit einer Zahl dahinter enthält (oder ein pin.it-Link ist) und keine Adresse eines Boards, Profils oder einer Suche ist.
  • Meldung, dass die Medien nicht ausgelesen werden konnten und der Pin öffentlich sein muss. PinViddl konnte das Bild aus diesem Pin nicht abrufen. Meist sind private, eingeschränkte oder gelöschte Pins die Ursache. Zum Testen öffnen Sie den Link in einem privaten Browserfenster. Verlangt Pinterest dort eine Anmeldung oder meldet, dass der Pin nicht verfügbar ist, kann PinViddl ihn ebenfalls nicht abrufen. Lässt sich der Pin dort problemlos öffnen, warten Sie ein paar Minuten und versuchen es erneut. Pinterest ändert seine Seiten von Zeit zu Zeit, und das kann jeden Downloader kurzzeitig stören.
  • Meldung, dass für diesen Pin keine herunterladbaren Medien gefunden wurden. Der Pin wurde geladen, aber es kam nichts Herunterladbares zurück. Versuchen Sie es mit dem vollständigen pinterest.com-Link statt eines Kurzlinks und probieren Sie einen anderen Pin aus, um zu sehen, ob das Problem an diesem Pin liegt.
  • Meldung, dass die Zwischenablage nicht gelesen werden kann. Ihr Browser hat die Schaltfläche „Einfügen“ blockiert. Halten Sie im Feld gedrückt und wählen Sie „Einsetzen“, oder drücken Sie Strg+V (am Mac Cmd+V).
  • Meldung, dass die Vorschau nicht verfügbar ist und Sie die Schaltfläche „Herunterladen“ nutzen sollen. Die Vorschau wurde nicht geladen, die Schaltfläche „Herunterladen“ funktioniert aber möglicherweise trotzdem.

Wenn ein öffentlicher Pin dauerhaft nicht funktioniert, schicken Sie den Link über die Kontaktseite, damit er geprüft werden kann.

Bevor Sie ein heruntergeladenes Bild weiterverwenden

Ein Pin ist das Werk eines anderen. Wenn Sie eine Kopie speichern, gehen damit weder die Rechte auf Sie über, noch dürfen Sie das Bild deshalb veröffentlichen, verkaufen, drucken oder erneut posten – auch dann nicht, wenn am Pin kein Wasserzeichen und keine Quellenangabe zu sehen ist. Ein Bild als persönliche Referenz aufzubewahren ist etwas anderes, als es in einem Blogbeitrag, einer Produktseite, einer Anzeige oder einem Social-Media-Beitrag zu verwenden. Dafür ist in der Regel die Erlaubnis des Urhebers nötig. Die Regeln unterscheiden sich je nach Land und Bild. Im Zweifel fragen Sie also den Urheber oder Rechteinhaber.
