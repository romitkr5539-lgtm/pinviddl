Pinterest-Bilder in voller Größe herunterladen

Pinterest macht das Speichern von Bildern in ihren Originalabmessungen etwas kompliziert. Wenn Sie versuchen, mit der rechten Maustaste auf einen Pin in Ihrem Browser zu klicken, speichern Sie möglicherweise dessen Miniaturansicht und nicht die tatsächliche Bilddatei. Der Pinterest Image Downloader auf PinViddl ist jedoch anders — Sie müssen nur die URL des Pins einfügen, und das Tool ruft das Bild in voller Größe zum Herunterladen und Speichern auf Ihrem Gerät ab.

Der Grund, warum das Speichern per Rechtsklick nicht funktioniert

Die Bilder, die Sie auf Pinterest sehen, sind lediglich Vorschauen, die für schnelles Laden optimiert sind. Daher kann es beim herkömmlichen Speichern eines Bildes passieren, dass Sie am Ende die Vorschau anstelle des tatsächlichen Bildes erhalten, das Pinterest veröffentlicht hat. Im Gegensatz dazu verwendet PinViddl nicht die Bilder im Feed, sondern die tatsächliche Seite des Pins; daher ist das Bild, das Sie erhalten, die echte Datei, die Pinterest veröffentlicht hat.

Sie müssen jedoch verstehen, dass PinViddl nicht mehr Daten produzieren kann als in dem Bild vorhanden sind. Wenn das vom Benutzer hochgeladene Bild von Anfang an winzig war, können Sie es in diesem Zustand herunterladen. PinViddl nimmt nur das, was zugänglich ist, und verbessert oder skaliert das Originalbild in keiner Weise.

Welche Pinterest-Links tatsächlich funktionieren

Bei der Arbeit mit dem Bild-Downloader-Tool möchten Benutzer die tatsächlichen Pin-URLs wie pinterest.com/pin/1234567890123456789 finden. Dies liegt daran, dass die üblichen pin.it-URLs normalerweise zu diesem bestimmten Pin weiterleiten.

Die Verwendung von Links zu Profilen, Boards oder Pinterest-Suchen führt zu keinen guten Ergebnissen, da diese Arten von URLs nicht auf bestimmte Bilder verweisen — es sind allgemeine Links, die normalerweise mehr als ein Bild enthalten. Falls versehentlich ein Board-Link kopiert wird, sollte der Benutzer durch das Board navigieren, um zum gewünschten einzelnen Pin zu gelangen.

Speichern der Datei auf einem Mobilgerät oder Desktop

Wenn Sie auf die Schaltfläche Herunterladen tippen, hängen die dann ausgeführten Aktionen vom verwendeten Webbrowser ab. Wenn Sie beispielsweise ein iPhone und Safari verwenden, wird das Bild normalerweise in einem neuen Seiten-Tab geöffnet, in dem Sie es gedrückt halten müssen, bevor Sie Bild speichern auswählen, um das Bild zur Fotos-App hinzuzufügen. Bei Android-Geräten mit Chrome wird die Datei normalerweise direkt in den Downloads-Ordner gesendet. Es gibt jedoch bestimmte Mobilgeräte, die das Bild während des Downloads in einen separaten Galerie-Ordner senden.

Was den Personal Computer betrifft — sei es Chrome, Edge, Firefox oder Safari — wird das Bild im dafür vorgesehenen Downloads-Ordner des jeweiligen Browsers gespeichert, wo es dann verschoben und aufgerufen werden kann.

Pinterest-Bildformate

Pinterest verwendet beim Teilen von Bildern verschiedene Formate. Die meisten auf Pinterest verwendeten Bilder sind Fotografien (.jpeg oder .jpg). Grafiken und Infografiken liegen normalerweise im PNG-Format vor, da PNG besser mit Volltonfarben oder Text funktioniert als JPEG, das Farben verzerren könnte. Manchmal verwendet Pinterest ein Bildformat namens WebP, das die meisten modernen Browser unterstützen, aber ältere Browser können Probleme damit haben.

PinViddl verwendet dieselben von Pinterest bereitgestellten Bildformate. Wenn ein Bildformat von Pinterest für einen bestimmten Pin bereitgestellt wird, dann wird genau dieses Format von PinViddl heruntergeladen. Das heruntergeladene Bild spiegelt nur das ursprüngliche Pinterest-Pin-Format wider. Dieselben Prinzipien gelten für Abmessungen — Bilder werden beim Herunterladen weder zugeschnitten noch in der Größe geändert.

Wenn ein Bild nicht heruntergeladen wird

Es gibt einige Gründe, die den Download eines Bildes verhindern können, und die gute Nachricht ist, dass die meisten davon gelöst werden können:

  • Möglicherweise sehen Sie keinen Bild-Pin. Einige Pins erscheinen im Feed visuell als statisches Bild, könnten aber Video-Pins sein, deren Titelbild ein Standbild des Videos ist. Prüfen Sie in diesem Fall, wie sich der Pin verhält, indem Sie darauf tippen — wenn der Pin abgespielt wird, müssen Sie stattdessen den Pinterest Video Downloader verwenden.
  • Es ist ein Multi-Bild-Idea-Pin. Pinterest hat mehrseitige Pins, die in Wirklichkeit aus mehreren Bildern bestehen. Je nachdem, wie der Pin eingerichtet ist, erhalten Sie möglicherweise nur das Titelbild — nicht jede Seite.
  • Die URL ist nicht die eines Pins. Es wurde eine falsche URL eingefügt, z. B. die eines Profils, Boards oder einer Suche anstelle des tatsächlichen Pins.
  • Der Pin ist privat, eingeschränkt oder gelöscht. Wenn das Konto oder Board keine öffentliche Sichtbarkeit hat, kann der Pin nicht gefunden werden.
  • Die URL war defekt oder hat sich beim Kopieren geändert. Manchmal kann es beim Kopieren über Ihr Mobilgerät passieren, dass die URL verkürzt oder der Link verändert wird. Kopieren Sie die URL stattdessen direkt aus der Adressleiste.
  • Pinterest hat einige Änderungen vorgenommen. Pinterest ändert von Zeit zu Zeit die Formatierung seiner Pin-Seiten, was bei der Verwendung von Online-Downloadern hinderlich sein kann. Wenn ein bestimmter Pin zuvor funktioniert hat, aber derzeit nicht, versuchen Sie es in ein paar Minuten erneut.

Suchen Sie einen Video-Pin oder eine Animation?

Nicht alle Inhalte auf Pinterest bestehen aus Bildern im herkömmlichen Sinne. Wenn Sie einen Pin sehen, der beim Ansehen abgespielt wird, handelt es sich wahrscheinlich um ein Video oder eine GIF-Animation. Für Video kann PinViddl als Pinterest Video Downloader verwendet werden. Wenn es eine kurze Schleifenanimation ist, die Sie möchten, können Sie stattdessen den Pinterest GIF Downloader verwenden.

Heruntergeladene Bilder verantwortungsvoll verwenden

Bilder auf Pinterest gehören demjenigen, der sie erstellt oder gepostet hat, auch wenn kein sichtbares Wasserzeichen oder eine Quellenangabe auf dem Pin vorhanden ist. Das Herunterladen eines Bildes mit PinViddl ändert nicht, wem es gehört, und gibt Ihnen keine Rechte, es zu veröffentlichen, zu verkaufen oder anderweitig wiederzuverwenden. Wenn Sie ein heruntergeladenes Bild für etwas anderes als den persönlichen Gebrauch verwenden möchten — einen Blogbeitrag, einen Produkteintrag, soziale Medien, Druck — suchen Sie zuerst den ursprünglichen Ersteller und holen Sie dessen Erlaubnis ein.
