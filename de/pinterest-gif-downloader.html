Was der Pinterest-GIF-Downloader leistet

Manche Pins bewegen sich: Sie laufen von selbst in einer Schleife. Wer so einen Pin speichert wie ein Foto, bekommt oft nur ein einzelnes Standbild oder gar nichts Brauchbares. Für genau diesen Fall ist diese Seite gedacht. Sie geben PinViddl den Link zu einem öffentlichen Pin, das Tool prüft, welche animierten Medien dieser Pin tatsächlich enthält, und bietet Ihnen einen Download an.

Das kann das Tool:

  • einen öffentlichen Pin über seinen Link auslesen,
  • die animierte Datei anbieten, die Pinterest für diesen Pin hat,
  • in einem normalen Browser auf Smartphone, Tablet oder Computer laufen.

Das kann es nicht:

  • ein Video in ein GIF oder ein GIF in ein Video umwandeln,
  • Boards, Profile oder Suchseiten herunterladen,
  • private Pins öffnen,
  • die Qualität der Originaldatei verbessern.

Eines sollten Sie vorab wissen: Die Datei, die Sie erhalten, ist nicht immer eine .gif-Datei. Warum das so ist und was Sie dann tun können, erklärt der Abschnitt zu GIF und MP4 weiter unten.

So laden Sie ein GIF von Pinterest herunter

  1. Öffnen Sie den animierten Pin in der Pinterest-App oder auf pinterest.com.
  2. Kopieren Sie den Link (Details dazu weiter unten).
  3. Fügen Sie den Link in das Feld oben auf dieser Seite ein, oder nutzen Sie die Schaltfläche Einfügen.
  4. Klicken Sie auf GIF herunterladen. Während PinViddl die Medien des Pins abruft, läuft ein Fortschrittsbalken.
  5. Speichern Sie die Datei, sobald die Download-Option erscheint. Für eine weitere Datei klicken Sie auf Weitere Datei herunterladen.

Link in der Pinterest-App kopieren. Öffnen Sie den Pin so, dass er den Bildschirm ausfüllt. Je nach App-Version finden Sie die Option unter Teilen oder hinter dem Menü mit den drei Punkten. In beiden Fällen brauchen Sie Link kopieren.

Link im Browser kopieren. Klicken Sie den Pin an, sodass er auf einer eigenen Seite geöffnet wird, und kopieren Sie die Adresse aus der Adresszeile. Wenn Sie noch auf einer Board- oder Suchseite sind und der Pin nur in einem Pop-up erscheint, prüfen Sie vor dem Kopieren, ob die Adresse jetzt /pin/ enthält.

Nach dem Download prüfen, was Sie bekommen haben. Sehen Sie sich den Dateinamen an. Er sollte auf .gif oder .mp4 enden. Blendet Ihr Gerät Dateiendungen aus, öffnen Sie die Dateidetails: unter Windows per Rechtsklick und „Eigenschaften“, am Mac über „Informationen“, auf dem iPhone durch langes Tippen auf die Datei in der Dateien-App. Was die einzelnen Ergebnisse bedeuten, erklärt der nächste Abschnitt.

GIF oder MP4: Was bekommen Sie?

Ein GIF ist ein Bildformat. Eine .gif-Datei enthält eine Folge von Einzelbildern mit jeweils höchstens 256 Farben und ohne Ton. Videoformate wie MP4 brauchen für denselben Clip meist weniger Daten. Deshalb spielen viele Websites, die GIFs zu zeigen scheinen, in Wahrheit kleine MP4-Dateien in Dauerschleife ab. Auf der Pin-Seite sehen beide gleich aus, man erkennt den Unterschied also nicht beim Zuschauen.

PinViddl rät nicht, sondern prüft, welches Medium der Pin hat, und bietet genau dieses an:

  • Ist das Medium des Pins ein GIF, laden Sie ein GIF herunter.
  • Ist es ein Video, laden Sie eine Videodatei herunter. In den meisten Playern läuft sie in einer Schleife, es ist aber keine .gif-Datei.
  • Steht keines von beiden in einer Form zur Verfügung, die PinViddl anbieten kann, gibt es keinen Download. Siehe dazu den Abschnitt zu Fehlern weiter unten.
Was Sie bekommen haben Was das bedeutet Was Sie tun können
.gif-Datei Das Medium des Pins war ein GIF Überall verwenden, wo GIFs unterstützt werden. Ob die Animation läuft, sehen Sie, wenn Sie die Datei im Browser öffnen.
.mp4-Datei Das Medium des Pins war ein Video Viele Apps spielen einen so kurzen Clip in Dauerschleife ab. Brauchen Sie eine echte .gif-Datei, müssen Sie die Datei umwandeln.

PinViddl wandelt keine Dateien um und empfiehlt auch keinen bestimmten Konverter. Wenn Sie ein MP4 selbst in ein GIF umwandeln, sollten Sie drei Dinge beachten: Das Ergebnis ist eine neue Datei, die der Konverter erzeugt hat, und nicht das Original. Es ist auf 256 Farben pro Bild begrenzt. Und es ist meist größer als das Video, aus dem es entstanden ist. Behalten Sie, wenn Ihr Konverter das erlaubt, die ursprünglichen Abmessungen bei. Eine niedrigere Bildrate oder Größe verkleinert die Datei, kostet aber Flüssigkeit in der Bewegung.

Welche Qualität Sie erwarten können

Sie erhalten die Datei so, wie Pinterest sie für den Pin vorhält. PinViddl vergrößert, schärft oder komprimiert sie nicht neu und kann sie daher nicht besser aussehen lassen als ihre Quelle. Die Quelle kann außerdem vom ursprünglichen Upload des Urhebers abweichen, weil Plattformen hochgeladene Dateien häufig weiterverarbeiten.

PinViddl nennt keine Auflösung, weil es nicht die eine Zahl dafür gibt. Abmessungen und Bildrate unterscheiden sich von Pin zu Pin. Bezeichnungen wie 1080p oder 4K stammen aus der Videowelt. Ein GIF hat schlicht eine Größe in Pixeln, und kein Downloader kann Pixel hinzufügen, die die Quelle nicht enthält.

Zwei Eigenschaften liegen am GIF-Format selbst und nicht an einem Downloader. Die Farbtiefe ist auf 256 Farben pro Bild begrenzt, weshalb weiche Farbverläufe streifig wirken können. Und die Dateigröße kann selbst bei wenigen Sekunden Animation überraschend hoch sein.

Pinterest-GIFs auf Smartphone oder Computer herunterladen

PinViddl läuft im Browser, deshalb sind die Schritte auf jedem Gerät gleich. Nur der Speicherort der Datei unterscheidet sich.

  • Android: Kopieren Sie den Pin-Link in der Pinterest-App, fügen Sie ihn im mobilen Browser in PinViddl ein und laden Sie die Datei herunter. Sie wird normalerweise im Ordner „Downloads“ gespeichert. Verschieben Sie sie in Ihre Galerie, wenn sie dort erscheinen soll.
  • iPhone und iPad: Die Schritte sind in Safari dieselben. Die Datei wird in der Dateien-App unter „Downloads“ gespeichert, nicht in der Fotos-App. Um sie zu den Fotos hinzuzufügen, öffnen Sie sie in „Dateien“, tippen auf „Teilen“ und wählen „Bild sichern“ oder „Video sichern“. Welche Option erscheint, hängt vom Dateityp ab.
  • Windows und Mac: Die Datei wird je nach Browsereinstellung im Ordner „Downloads“ gespeichert, oder es erscheint ein Speicherdialog.

Zwei Kleinigkeiten überraschen viele. Manche Browser öffnen Mediendateien in einem neuen Tab, statt sie zu speichern. Halten Sie die Datei dann gedrückt (oder klicken Sie mit der rechten Maustaste darauf) und wählen Sie die Speicheroption des Browsers, zum Beispiel „Verknüpfte Datei laden“ oder „Link speichern unter“. Außerdem zeigen manche Galerie-Apps ein gespeichertes GIF nur als Standbild an. Bewegt sich Ihres nicht, öffnen Sie die Datei in einem Browser oder einer Messenger-App und prüfen Sie, ob die Animation erhalten ist.

Wenn der Download fehlschlägt

Der Link ist das Problem

  • Er verweist auf ein Board, ein Profil oder eine Suchseite. Öffnen Sie den einzelnen Pin und kopieren Sie dessen eigenen Link.
  • Er wurde beim Kopieren abgeschnitten. Kopieren Sie ihn noch einmal vollständig.
  • Ein pin.it-Teilen-Link ist abgelaufen oder wurde falsch kopiert. Kopieren Sie ihn erneut aus dem Teilen-Menü.

Der Pin ist das Problem

  • Er wurde gelöscht. Öffnen Sie ihn in Pinterest. Ist er weg, gibt es nichts herunterzuladen.
  • Er ist privat oder eingeschränkt. Nur öffentliche Pins lassen sich lesen.
  • Es ist ein Standbild. Nutzen Sie den Pinterest-Bild-Downloader.
  • Es ist ein normales Video. Nutzen Sie den Pinterest-Video-Downloader.
  • Er enthält kein Medium, das PinViddl anbieten kann. Versuchen Sie es später noch einmal. Schlägt es weiterhin fehl, lässt sich dieser Pin hier nicht herunterladen.

Die Ursache liegt außerhalb des Pins

  • Pinterest ist langsam oder lehnt Anfragen vorübergehend ab. Warten Sie ein paar Minuten und versuchen Sie es erneut.
  • Pinterest hat den Aufbau seiner Seiten geändert. PinViddl liest öffentliche Pin-Seiten, daher kann eine Änderung auf Seiten von Pinterest die Abfrage stören, bis das Tool angepasst ist.
  • Es gibt ein Verbindungs- oder Browserproblem. Laden Sie die Seite neu, prüfen Sie Ihre Verbindung oder probieren Sie einen anderen Browser aus. Ein veralteter Browser oder ein aggressiver Blocker kann jedes Web-Tool stören.

Weiterhin ohne Erfolg? Schicken Sie den Pin-Link, Ihr Gerät, Ihren Browser und ungefähr den Zeitpunkt über die Kontaktseite. Ein Link, der funktionieren sollte, es aber nicht tut, ist für uns eine nützliche Information.

Was PinViddl von Ihnen braucht

Nur den Pin-Link. Auf dieser Seite gibt es keine Pinterest-Anmeldung, kein PinViddl-Konto und keine Registrierung.

Der Link wird an das Backend von PinViddl gesendet, das auf Cloudflare Workers läuft. Das Backend ruft die öffentliche Pin-Seite bei Pinterest ab und liest die Adresse des Mediums aus. Laut Datenschutzerklärung gilt dabei:

  • Pin-Links werden für die Anfrage verarbeitet und nicht gespeichert.
  • Übliche Server-Protokolle mit IP-Adresse und Zeitstempeln werden aus Sicherheitsgründen und zur Missbrauchsabwehr bis zu 30 Tage aufbewahrt.
  • Analysedaten werden aggregiert und bis zu 26 Monate aufbewahrt.
  • Die Website bindet keine Werbenetzwerke und keine Tracking-Pixel sozialer Netzwerke ein.
