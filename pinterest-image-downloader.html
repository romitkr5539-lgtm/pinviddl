How to download an image from Pinterest

  1. Copy the Pin's link. On pinterest.com, open the Pin so it has a page of its own, then copy the address from your browser's address bar. In the Pinterest app, tap the Pin, tap Share, then Copy link.
  2. Paste it into the box above. The Paste button pulls the link from your clipboard, or you can paste it yourself. The link has to start with https://.
  3. Press Download Image. A progress bar runs for a couple of seconds while PinViddl looks up the Pin.
  4. Look at the preview. The image appears with at least one row beneath it. Each row has a Copy URL button, which copies the direct address of the image file, and a Download button.
  5. Press Download. Where the file lands depends on your device (see below). Use Download another image to start over with a new link.

Pinterest has its own option too. On some Pins, the ⋯ menu includes Download image, according to Pinterest's help page. When it's there, use it. PinViddl is for the times it isn't, or when all you have is a link someone sent you.

Which Pinterest links work

  • https://www.pinterest.com/pin/123456789/ — Works. This is the standard Pin link.
  • https://pin.it/AbCd123 — Usually works. These are the short links from Pinterest's Share menu. If one fails, open it in your browser and copy the full address instead.
  • https://in.pinterest.com/pin/… or https://pinterest.co.uk/pin/… — Works. Regional addresses on the tool's list are accepted.
  • A board, profile or search link — Rejected. These point to many images, not one. Open the Pin you want and copy its link.
  • A direct image address (i.pinimg.com/…) — Rejected. Use the link to the Pin's page.
  • A link without https:// — Add https:// at the start.

A few less common regional Pinterest domains aren't recognized. If yours is rejected, swap the domain for www.pinterest.com and keep the /pin/ and the number after it, which usually works.

Saving the image on iPhone, Android or a computer

PinViddl hands the file to your browser, so what happens next depends on the browser.

  • iPhone (Safari). The file may go to the Files app under Downloads, or open as a plain image. If it opens, touch and hold it and choose Add to Photos.
  • Android (Chrome). Downloads normally land in the Downloads folder, and some gallery apps list them separately. If the image opens in a tab instead, touch and hold it and choose Download image.
  • Computer. Chrome, Edge, Firefox and Safari normally save to your Downloads folder. If the image opens in a tab, right-click it and choose Save image as.

What to expect from the image quality

PinViddl looks up the image file attached to the Pin and passes it to you. It doesn't upscale, sharpen or enhance anything, so the result can't be better than what Pinterest has for that Pin.

That matters because the picture in a feed is often a reduced copy of the upload, and some uploads were small to begin with. If a download looks smaller than you hoped, check whether the Pin itself is low resolution.

To see what you actually got, look at the file's dimensions rather than trusting a label: Properties on Windows, Get Info on a Mac, or the Info panel in your phone's photo app. If you need something bigger, the creator's own website or portfolio is the better place to look.

The file type is whatever Pinterest serves for that Pin, most often JPG and sometimes PNG or WebP. PinViddl isn't a converter, so there's no option to change formats.

If the download doesn't work

The tool shows short messages when something goes wrong. Here is what each one usually means.

  • "Please insert a valid Pinterest URL…" The link was rejected before anything was sent. Check that it starts with https://, contains /pin/ followed by a number (or is a pin.it link), and isn't a board, profile or search address.
  • "Media extraction failed. Please make sure the Pin is public." PinViddl couldn't get the image from that Pin. Private, restricted and deleted Pins are the usual cause. To test, open the link in a private browsing window. If Pinterest asks you to log in or says the Pin isn't available, PinViddl can't fetch it either. If the Pin opens fine there, wait a few minutes and try again, since Pinterest changes its pages from time to time and that can briefly break any downloader.
  • "No downloadable media found for this Pin." The Pin loaded but nothing downloadable came back. Try the full pinterest.com link instead of a short one, and try a different Pin to see whether the problem is that Pin.
  • "Unable to read clipboard. Please paste manually." Your browser blocked the Paste button. Touch and hold in the box and choose Paste, or press Ctrl+V (Cmd+V on a Mac).
  • "Preview unavailable — use the Download button below." The preview didn't load, but the Download button may still work.

If a public Pin keeps failing, send its link through the Contact page so it can be checked.

Before you reuse a downloaded image

A Pin is someone's work. Saving a copy doesn't transfer ownership or give you permission to publish, sell, print or repost it, even when there's no watermark or credit on the Pin. Keeping an image for personal reference is different from putting it in a blog post, product listing, ad or social post, which usually calls for the creator's permission. The rules vary by country and by image, so if you're unsure, ask the creator or rights holder. PinViddl's Disclaimer explains the intended use. None of this is legal advice.
