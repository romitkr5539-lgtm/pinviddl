What this Pinterest GIF downloader does

Some Pins move. They loop on their own, and if you try to save one the way you'd save a photo, you often end up with a single still frame, or nothing usable at all. This page is for that situation. You give PinViddl the link to one public Pin, it checks what animated media that Pin actually has, and it offers you a download.

What it does:

  • Reads one public Pin from its link.
  • Offers the animated file Pinterest has for that Pin.
  • Works in a normal browser on a phone, tablet or computer.

What it doesn't do:

  • Turn a video into a GIF, or a GIF into a video.
  • Download boards, profiles or search pages.
  • Open private Pins.
  • Improve the quality of the original file.

One thing is worth knowing before you start: the file you get isn't always a .gif. The section on GIFs and MP4s below explains why, and what to do about it.

How to download a GIF from Pinterest

  1. Open the animated Pin in the Pinterest app or on pinterest.com.
  2. Copy its link (details below).
  3. Paste the link into the box at the top of this page, or use the Paste button.
  4. Select Download GIF. A progress bar shows while PinViddl looks up the Pin's media.
  5. Save the file when the download option appears. To fetch another file, select Download another file.

Copying the link in the Pinterest app. Open the Pin so it fills the screen. Depending on your app version, the option sits under Share or behind the three-dot menu. Either way, you want Copy link.

Copying the link in a browser. Click the Pin so it opens on its own page, then copy the address from the address bar. If you're still on a board or search page with the Pin shown in a pop-up, check that the address now includes /pin/ before copying.

After the download, check what you got. Look at the file name. It should end in .gif or .mp4. If your device hides extensions, open the file's details (right-click and Properties on Windows, Get Info on Mac, or tap and hold the file in Files on iPhone). Will you get a GIF or an MP4?

A GIF is an image format. A .gif file holds a sequence of frames, each limited to 256 colours, with no sound. Video formats like MP4 usually store less data for the same clip, which is why many sites that look like they're showing GIFs are actually playing small MP4 files on repeat. On a Pin page the two look identical, so you can't tell by watching.

PinViddl doesn't guess. It checks what media the Pin has and offers that:

  • If the Pin's media is a GIF, you download a GIF.
  • If it's a video, you download a video file. It will loop in most players, but it won't be a .gif.
  • If neither is available in a form PinViddl can offer, there's no download. See the failure guide below.
What you got What it means What to do
.gif file The Pin's media was a GIF Use it anywhere GIFs are supported. To check the animation, open it in a browser.
.mp4 file The Pin's media was a video Many apps will play a short clip like this on repeat. If you need an actual .gif file, convert it.

PinViddl doesn't convert files, and it doesn't recommend a particular converter. If you do convert an MP4 to a GIF, keep three things in mind. The result is a new file made by that converter, not the original. It's limited to 256 colours per frame. It's usually larger than the video it came from. If your converter lets you, keep the original dimensions. Lowering the frame rate or size shrinks the file but costs smoothness.

What quality to expect

You get the file as Pinterest holds it for that Pin. PinViddl doesn't upscale, sharpen or re-compress it, so it can't look better than its source. The source may also differ from what the creator first uploaded, because platforms often process uploads.

PinViddl doesn't list a resolution because there isn't one number to give. Dimensions and frame rate vary from Pin to Pin. Labels like 1080p or 4K are video terms. A GIF simply has a pixel size, and no downloader can add pixels the source doesn't have.

Two traits come from the GIF format itself rather than from any downloader. Colour is limited to 256 per frame, so smooth gradients can look banded. File size can also be surprisingly large, even for a few seconds of animation.

Pinterest GIF downloader on phone or computer

PinViddl runs in your browser, so the steps are the same on every device. Only the place the file lands differs.

  • Android: copy the Pin link in the Pinterest app, paste it into PinViddl in your mobile browser, and download. The file normally goes to your Downloads folder. Move it into your gallery if you want it there.
  • iPhone and iPad: same steps in Safari. The file is saved in the Files app, under Downloads, not in Photos. To add it to Photos, open it in Files, tap Share, and choose Save Image or Save Video. Which one you see depends on the file type.
  • Windows and Mac: the file goes to your Downloads folder or a save prompt, depending on your browser settings.

Two small things catch people out. Some browsers open media files in a new tab instead of saving them. If that happens, press and hold the file (or right-click it) and choose the browser's save or download-linked-file option. And some gallery apps show a saved GIF as a still frame. If yours doesn't move, open the file in a browser or a messaging app to check the animation is intact.

If the download fails

The link is the problem

  • It points to a board, profile or search page. Open the single Pin and copy its own link.
  • It was cut off when copied. Copy it again in full.
  • A pin.it share link has expired or was copied wrongly. Re-copy it from the Share menu.

The Pin is the problem

  • It was deleted. Open it in Pinterest. If it's gone, there's nothing to download.
  • It's private or restricted. Only public Pins can be read.
  • It's a still image. Use the Pinterest Image Downloader.
  • It's a regular video. Use the Pinterest Video Downloader.
  • It has no media PinViddl can offer. Try again later. If it keeps failing, that Pin can't be downloaded here.

Something outside the Pin

  • Pinterest is slow or temporarily refusing requests. Wait a few minutes and retry.
  • Pinterest changed how its pages are built. PinViddl reads public Pin pages, so a change on Pinterest's side can break lookups until it's adjusted.
  • A connection or browser problem. Refresh, check your connection, or try another browser. An outdated browser or aggressive blocker can interfere with any web tool.

Still stuck? Send the Pin link, your device and browser, and roughly when it happened through the Contact page. A link that should work but doesn't is useful to know about.

Before you reuse a downloaded GIF

Being able to download a GIF doesn't mean you own it. Whoever made or posted it usually keeps the rights, and not everything on Pinterest is free to reuse. Giving credit isn't the same as having permission.

Saving a copy for your own reference is one thing. Posting it publicly, editing and sharing it, or using it in anything commercial normally needs the creator's permission. If you're unsure, ask, or use GIFs whose licence clearly allows what you want to do. This is general guidance, not legal advice. See the Disclaimer for PinViddl's position.
